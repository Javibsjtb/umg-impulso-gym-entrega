# Git y colaboración · entrega

Este repositorio contiene una versión de entrega publicada desde la Mac del titular de la cuenta GitHub `Javibsjtb`. El commit inicial representa la publicación de una versión integrada del prototipo; no se presenta como historial de cinco estudiantes ni como evidencia de sprints ya ejecutados.

Las invitaciones de colaboración con permiso de escritura se enviaron a `Lilmaarx` y `crmarjorie` el 2/11/2026. Aceptarlas y aportar cambios reales es responsabilidad de cada cuenta.

El proyecto original y su historial técnico están en `Javibsjtb/umg-impulso-gym`. Para la evaluación se entrega aquí el código completo y el PRD en PDF. Los cinco integrantes deberán realizar contribuciones, revisiones y seguimiento reales si el docente exige evidencia de colaboración.

No se incluyen `.env`, claves de producción, contraseñas ni base de datos local. El equipo debe validar un negocio real y registrar su evidencia antes de presentar el producto como solución implementada para ese negocio.
